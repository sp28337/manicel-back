# Manicel Backend — FastAPI Application

🌐 **Production:** https://manicel.ru/


This repository contains the backend part of the **Manicel** project, built with **FastAPI**.  
Although this backend was developed first, it now serves as the API for the production frontend application.

The project was created as part of my early backend journey and closely aligns with the technologies and concepts studied during a **FastAPI backend course on Stepik**. The main focus was on understanding backend architecture, API design, asynchronous Python, configuration management, database migrations, and authentication.

The backend uses a modern Python stack including **FastAPI, Pydantic v2, SQLAlchemy 2 (async), Alembic, PostgreSQL**, and JWT-based authentication. The project is containerized with Docker, includes automated tests, and is prepared for production deployment using Gunicorn and Uvicorn workers.

This repository represents my first serious backend application and became the foundation for further fullstack development.

---

## Tech Stack

- Python 3.12
- FastAPI
- Pydantic v2
- SQLAlchemy 2 (async)
- Alembic
- PostgreSQL
- JWT authentication (python-jose)
- Pytest (async)
- Docker, Docker Compose
- Gunicorn + Uvicorn workers
